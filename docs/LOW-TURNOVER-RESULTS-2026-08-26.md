## 0. 한 줄 결론

**저변동성 신호가 벤치마크를 못 이긴다.** 비용도 회전율도 설계대로 통제됐고
자본 제약도 제거했는데 초과수익이 **연 -1.94%p** 다. 실행이 아니라 아이디어의
문제이므로 고칠 구석이 없다.

## 1. 두 실행 비교 — 자본 제약이 원인인지 가른 실험

1차(자본 1,000만원)에서 종목당 예산이 40만원이라 후반에 고가주가 최대 4개까지
빠졌다. 그것이 원인인지 확인하려고 자본을 5배로 올려 다시 돌렸다.

| | 자본 1,000만 | 자본 5,000만 |
|---|---|---|
| 순수익 | +21.49% (연 +1.99%) | +23.17% (연 +2.13%) |
| 벤치마크 | +48.50% (연 +4.07%) | +48.50% |
| **초과수익** | **-27.01%** | **-25.33%** |
| MDD | -10.47% | -10.71% |
| 연 회전율 | 1.26배 | 1.35배 |
| 총비용 | 자본의 2.98% | 자본의 3.20% |
| 예산초과 | 0 → **4개** | **전부 0** |
| 보유 종목 | 21~25 | **항상 25** |
| Deflated Sharpe | 0.9827 | 0.9903 |

**자본 제약을 완전히 해소했는데 초과수익 개선은 +1.68%p 뿐이다.** 예산초과가
4개에서 0으로, 보유가 항상 25종목으로 채워졌는데도 그렇다. 자본 규모는
원인이 아니었다.

## 2. 설계는 전부 의도대로 작동했다

이것이 이번 실패를 이전 실패들과 다르게 만든다.

| 설계 목표 | 결과 |
|---|---|
| 연 회전율 ≤ 2배 | **1.35배** ✅ |
| 비용을 우위보다 작게 | **연 0.32%** ✅ (폐기한 전략들은 연 3~11%) |
| 손절 없이 위험 관리 | **MDD -10.7%** ✅ 10년간 |
| 다중검정 보정 통과 | **DSR 0.9903** ✅ (시도 5회 선언) |
| 총 거래 ≥ 40 | 255건 ✅ |
| **벤치마크 대비 초과수익 > 0** | **-25.33%** ❌ |

폐기한 일봉 전략들은 **비용이 우위를 먹어서** 졌다. 이번엔 비용이 통제된
상태에서 **신호 자체가 가치를 더하지 못했다.** 6개 기준 중 5개를 통과하고
결정적인 하나에서 진 것이므로, 원인이 명확하고 논쟁의 여지가 적다.

Deflated Sharpe 가 통과했다는 점도 기록해 둔다 — 이 수익이 운이 아니라는
뜻이다. 다만 **"통계적으로 진짜"와 "벤치마크보다 낫다"는 다른 문제**였고,
후자에서 졌다.

## 3. 가장 결정적인 비교 — 종목을 고를 필요가 없었다

이 전략의 존재 이유는 "낮은 변동성" 이었고, MDD -10.7% 는 실제로 나왔다.
그런데 같은 결과를 훨씬 싸게 얻을 수 있다:

| | 연 수익 | 회전율 | 비용 |
|---|---|---|---|
| **저회전 전략** | **+2.13%** | 1.35배 | 자본의 3.20% |
| 벤치마크 50% + 현금 50% | +2.04% | ~0 | ~0 |
| 벤치마크 55% + 현금 45% | +2.24% | ~0 | ~0 |

**유니버스를 절반만 사고 나머지를 현금으로 두면 거의 같은 수익이 나온다.**
회전율도 비용도 없이. 변동성을 낮추는 것이 목적이라면 종목을 고를 이유가
없었다.

이것은 저변동성 팩터에 대한 표준적인 반론이고, 이번에 우리 데이터로 직접
확인됐다.

## 4. 이 결과의 한계 (결론을 약화시키지 않지만 기록한다)

### (가) 벤치마크가 생존편향으로 부풀려져 있다

벤치마크의 2,094종목은 **캐시에 CSV 가 남아 있는 = 끝까지 살아남은** 종목들이다.
상장폐지분이 빠져 실제보다 높게 나온다. 이 편향을 걷어내면 격차가 줄어들 수
있지만 **25%p 를 다 메울지는 알 수 없다.**

`KrxUniverse.union_between` 이 이 문제를 위해 있지만 이번 실행은
`provider.universe()` 를 썼다. 다시 잰다면 여기부터 고쳐야 한다.

### (나) 벤치마크의 MDD 를 재지 않았다

전략 MDD -10.7% 가 벤치마크보다 얼마나 낮은지 비교가 없어서 "위험조정 후에는
나았다" 고 말할 근거가 없다. 다만 §3 의 "현금 50%" 비교가 그 반론을 대체로
막는다 — 위험을 낮추는 더 싼 방법이 있기 때문이다.

### (다) 가치 팩터를 넣지 못했다

규격 §8 대로 재무 데이터 경로가 없어 **저변동성 단독**으로 돌렸다. 규격의
절반만 시험한 셈이다. 다만 한국에서 가치 팩터의 증거도 엇갈리므로(선물연구
2020 에서 복제 목록에는 있으나 Fama-MacBeth 에서 HML 프리미엄은 유의하지 않음)
이것이 결과를 뒤집을 것으로 기대할 근거는 약하다.

## 5. 하지 말 것

규격 §6 에 사전등록한 대로 **폐기하고 손잡이를 돌리지 않는다.**

지금 시도하고 싶어지는 것들과 하지 말아야 하는 이유:

- **보유 종목 수 변경** (25 → 15/40) — 같은 fold 여섯 번째 참조
- **리밸런싱 주기 변경** (반기 → 분기/연간) — 위와 같음
- **변동성 창 변경** (60일 → 120일/20일) — 위와 같음
- **밴딩 폭 조정** (25/40 → 20/50) — 위와 같음

Bailey et al. (AMS 2014): 과최적화된 전략의 표본 외 기대수익은 0 이 아니라
**음수**다. 다섯 번 본 데이터에서 통과 조합을 찾는 것은 그 지점 그대로다.

## 6. 남은 것

측정된 사실:

```
유니버스를 그냥 동일가중으로 사서 들고 있으면   연 +4.07%
우리가 저변동성으로 25종목을 고르면            연 +2.13%
→ 종목 선택이 연 2%p 를 까먹었다
```

`docs/STRATEGY-RESET-2026-08-26.md` §8-2 에 적어 둔 대로, 정직한 다음 행동은
"다른 전략 찾기" 가 아니라 **저비용 지수 투자 + ISA 세제 활용**이다.

ISA 는 배당 2.5% 가정 시 5,000만원 기준 **연 약 0.4% 절세이고 위험도
추적오차도 0** 이다. 이 저장소에서 만든 어떤 전략보다 확실한 수익원이다.
(단, 2026 한도·세율은 국세청 원문 확인 필요 — 검증 부채로 남아 있다)
